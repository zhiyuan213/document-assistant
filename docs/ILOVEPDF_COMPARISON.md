# PDF 工具对照与扩展

对照来源：[iLovePDF 官方工具列表](https://www.ilovepdf.com/)，查看日期：2026-10-14。独立实现功能，不复制网站品牌或素材。

## 本次增加

| 工具 | 当前实现 |
| --- | --- |
| PDF 旋转 | 全部或指定页顺时针旋转 90/180/270 度 |
| 提取页面 | 按输入页码顺序输出一个 PDF |
| 删除页面 | 删除指定页码，至少保留一页 |
| 调整页序 | 输入所有页码的新顺序，不重复、不遗漏 |
| 添加页码 | 起始编号可设为 1–9999，顶部或底部居中；含旋转页暂不支持 |

上述工具复用匿名身份、次数开关、分享收藏、下载和 30 分钟自动清理。无需新增数据库表或环境变量。首页保留九个常用入口，新工具在“全部工具”中提供。文件上限、页数上限和加密限制与原有 PDF 工具一致。

## 已有功能与差异

已有合并、拆分、压缩、图片与 PDF 互转、Word 转 PDF、水印、加密与解密。PDF 转 Word 当前仅提取文字，不保证复杂排版，也不处理扫描件；PDF 转图片当前逐页渲染，不提供嵌入图片提取。

## 尚未实现

| 类别 | 缺少功能 | 后续实现条件 |
| --- | --- | --- |
| Office 转换 | Excel/PPT 转 PDF | 安装 LibreOffice 对应组件并验证字体、表格分页和幻灯片布局 |
| 可编辑转换 | PDF 转 Excel/PPT | 引入并验证表格或版面识别引擎，不能将图片输出冒充可编辑文档 |
| 识别 | OCR、扫描文档矫正 | 增加 OCR 引擎及中文模型；相册选图已支持，但不等同于扫描矫正 |
| 编辑 | 裁剪、签名、文字/图片批注、表单 | 增加页面预览与触控编辑，明确签名属于图片签名还是证书签名 |
| 安全 | 永久遮盖敏感信息 | 必须移除底层内容并验证，不能仅盖一个色块 |
| 文档处理 | 修复、PDF/A、比较、HTML 转 PDF | 分别验证损坏文件恢复、归档标准、差异展示及网页渲染 |
| 智能工具 | 摘要、翻译、Markdown | 需要可靠内容解析；AI 服务需配置及明确费用、隐私和能力限制 |
| 流程 | 多工具连续处理 | 增加流程编排与中间文件清理 |

以上列为后续清单，不提供尚未实现的可点击入口。
