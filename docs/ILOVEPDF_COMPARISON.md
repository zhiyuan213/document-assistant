# PDF 工具对照与扩展

对照来源：[iLovePDF 官方工具列表](https://www.ilovepdf.com/)，更新日期：2026-10-16。独立实现，不复制品牌或素材。

当前共26个基础工具，全部永久免费，复用分享、收藏、下载及30分钟定时清理。

## 当前能力

原有15项：PDF转Word、Word转PDF、合并、拆分、压缩、图片转PDF、PDF转图片、水印、加密、解密、旋转、提取页面、删除页面、调整页序、页码。

本次新增：

| --- | --- |
| Excel 转 PDF | LibreOffice Calc 转换 XLS/XLSX，按打印设置分页 |
| PPT 转 PDF | LibreOffice Impress 转换 PPT/PPTX，动画不保留 |
| OCR | 本地 Tesseract 中英文识别，输出带文字层的图片PDF，20页、120秒上限 |

PDF转Word仍仅提取文字，不保证复杂排版；扫描件可先OCR再转Word。Office转换可能受字体与源文件打印设置影响。裁剪与图片签名暂不支持旋转页。嵌入图片提取不包含内联图片，不保证与页面上的外观相同。

## 未提供同等能力的项目

- 可编辑的PDF转Excel/PPT：缺少经过验证的表格及版面重建引擎，不用图片结果冒充可编辑转换。
- 完整可视编辑、交互表单、手写签名画板：现有坐标工具并非页面拖拽编辑器，还需要预览、触控定位和表单字段交互。
- PDF/A：必须增加归档标准转换与独立一致性校验，普通重写不等同PDF/A。
- 网页HTML转PDF：需要独立网页渲染沙箱、网络访问限制及资源加载管理。
- AI当前仅保留总结和翻译。总结可导出Word/PDF报告，翻译支持12种目标语言；不保留原PDF版式。真实模型调用需部署新后端后验证。
- 自动扫描边缘识别/透视矫正、多工具连续流程：图片转PDF已有相机选图，但未实现自动矫正及流程编排。
- 平台电子签署邀请、证书签名及语义比较：不属于当前图片签名或像素比较能力。

## 部署与验证

镜像新增LibreOffice Calc/Impress、Tesseract中英模型以及Poppler。无需增加数据库表或环境变量。OCR官方行为参考：[Tesseract命令行](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html)。

自动测试验证裁剪边界、签名图片与越界、提取图片、修复后页数、Markdown文字、比较差异像素以及遮盖后无法提取原文字。实际容器转换和页面渲染验证记录见FUNCTION_CHECK.md。真机选图、分享图标、文件发送等须另行验证。
